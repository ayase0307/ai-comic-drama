# 改稿復驗、重抽上限與驗收原則

> 來源：外部 AI 短劇導演技能 R5、玄幻打鬥編導、特效導演的文字蒸餾，守富裁決併入（D8、D10、D25；局部修正寫法見 `storyboard/vfx-design-and-review.md` §6）。
> 不另立門禁：照常走依賴帳本（`h3d deps`）、段級核准（`references/tooling.md` §2.6）與 `h3d verdict`；本檔規定的是改稿與重抽時**要交代什麼**。H3 失敗模式的診斷順序仍以 `references/h3/failure-triage.md` 為準。

## §1 改稿必附改動清單＋聯動結論

任何重做（劇本、分鏡、提示詞、單段重抽改稿）交給使用者時附：

1. **改動清單**：改了哪幾段／哪幾鏡、改什麼、為什麼。
2. **聯動檢查**（逐項寫「有影響／無影響」）：伏筆與回收 → 角色狀態與人物賬 → 資訊量 → 因果節拍 → 資產錨點（服裝、道具、場景狀態）→ 時長與台詞預算 → 畫幅構圖。
3. **聯動結論**：哪些下游段因此要重審（對照 `h3d deps --status` 的 `prompt_stale`）。

沒有聯動結論的改稿不交給使用者審。

## §2 重抽與改稿的分界

- 同一個錯出現兩次 → 不再重抽，改稿。
- 每次錯的不一樣 → 可以重抽。
- **同一鏡隨機重抽最多 2 次**；第 3 次之前停下診斷，判斷錯在哪一層並回到那一層修：
  - 臉、服裝、道具錯 → 回階段 2 資產或階段 5 參考圖綁定；
  - 走位、構圖、動作邏輯錯 → 回階段 4 分鏡；
  - 寫法造成的錯（否定詞反向、指代不明、一鏡過載）→ 回階段 5 提示詞。
- 診斷與決定寫進 `h3d verdict` 的原因欄。
- **動作中段反覆失敗 → 改用省略**（抖音蒸餾 2026-10 A 批）：同一個動作的中段（接觸、揮擊、端杯落桌那一下）重抽兩次還是壞，不要死磕重抽，改成不直接拍那一下：
  - 用**反應鏡**（被打的人、旁觀者的臉）、**聲音**（擊中聲、杯子落桌聲，畫外）或**切點**（切在動作前、接在動作後的結果）交代事件；
  - 前後兩鏡的動勢方向要對上，跨越不同動作階段要有橋接（例如手已經舉起 → 切反應 → 回來時杯子已在桌上）；
  - 一段裡有一半能用就剪那一半（handle／trim，D12），壞掉的那一段用省略帶過。
  - 這是第三條路：重抽、回改分鏡之外，改分鏡時優先考慮省略，成本最低。改法照 §1 附改動清單。
  - 來源：抖音蒸餾 2026-10，栗子 7603676309234928902（端杯：失敗 → 修正 → 挑後半段 → 組接的完整修正鏈）。證據強度：外部，未經 H3 實測。

### §2.1 站位與朝向錯：先分三種（2026-10 Foyege 併入，D44）

| 錯誤出現的時機 | 錯在哪一層 | 先查 |
|---|---|---|
| 一開始就錯位、認錯人 | 世界層或映射層 | 站位附表／`staging/*.json`／`positions` 本身對不對；`subject_definitions`、`refmods` 的 `<Subject N>`↔`<Picture N>` 有沒有對錯（`storyboard/continuity-ledger.md` §4 三層對照） |
| 開頭對，鏡頭一動就亂、人數變了 | 攝影機層 | 第 2 鏡起是不是又重列了全場站位（W45）；運鏡是不是超出一個主運鏡 |
| 位置都對，只有對視、朝向不成立 | 攝影機層 | 補身體朝向與視線的螢幕方向、對話軸線（W41、`storyboard/continuity-ledger.md` §5；整段沒有視線句是 D07） |

常見症狀（補 `h3/failure-triage.md`；那份與上游 h3-video-prompting 同步、不在本 repo 改）：

| 症狀 | 常見原因 | 第一步修 | 不要做 |
|---|---|---|---|
| 正反打兩人看同一個方向 | 只寫「A 看 B」沒給螢幕方向 | 視線寫 `toward frame left／off-screen right`，過肩前景寫在哪個角（W41） | 整段重寫、加形容詞 |
| 中段人數變了、站位重新分配 | 第 2 鏡起又重列全場站位，模型重新分配空間 | 刪掉中段的全場站位，只寫這一鏡的變化（W45） | 把站位寫得更長 |
| 全身鏡臉變油、變糊 | 遠景另外加了毛孔、絨毛等近景膚質字 | 刪掉該鏡另外加的膚質字（W43）；守富定版皮膚段不動 | 加 8K、超高清 |

- **不要一出錯就把提示詞寫更長**：先判斷是世界關係、身份對應，還是這一鏡的問題，只改那一層。
- **先用 3–5 秒無對白試抽**：多人站位、新場景、第一次用的寫法，先拿最短、不含台詞的版本抽一次（REMIX `single480`／draft，或最短量子 56 幀），只看四件事：認錯人沒、人和家具的關係變了沒、鏡頭一動人數增減沒、正反打左右翻了沒。過了再加台詞與完整時長。這是流程建議，省的是長段重抽的機器時間。
- 來源 Foyege（c1wWFrcy8wQ、T4QqUf5i-OI），H3 0 實測。

## §3 驗收原則

- **比較改稿要固定其他變量**：同模型、同時長、同參考圖、同畫風、同場景；一次只改一件事，否則不知道是哪個改動起作用。
- 沒有固定種子的單次結果標「探索性」，不宣稱穩定或因果；單次樣本、同條件復現、跨模型驗證分開記。
- **局部失敗不擴成永久禁令**：一次失敗只證明那條路線在那個條件下失敗，寫進失敗目錄時註明條件。
- 組合有效不拆成單詞功效（不能說「因為寫了 pyro 所以有效」）。
- 不用字數、詞頻或術語數量代替看成片；沒看過成片不說「直出」「已驗證」。
- 動作慢不要先怪「文字太長」；不要用縮短、固定三段、減切鏡、禁止停頓來解速度問題，先回到動作本身。
