# 特效鏡設計卡、可讀性防線與驗收返修

> 來源：外部「AI 影視特效導演」技能（4 份文件 237 行，2026-09-24 快照）文字蒸餾，守富裁決併入（D35–D39）。
> 證據等級：外部有 8 組**單張靜幀**生圖實測文字紀錄（無固定種子、單次樣本）；**沒有影片、沒有 H3 實測**。下列是寫法與審圖規範，影片時序要自己驗。
> 與 `h3-combat-impact`、`combat-and-vfx-library.md` 五段鏈並用：五段鏈管「大招怎麼走完」，本檔管「每一個特效寫到什麼程度、生完怎麼判」。
> 外部原文的 12 種基礎效果目錄與 5 種主視覺範例存於蒸餾專案（distill-2/raw-vfx-01、02），需要時查，不在此重抄。

## §1 先選規模

| 規模 | 畫面職責 | 常見錯 |
|---|---|---|
| 局部寫實 | 效果只在接觸物與鄰近表面，人物或場景是主角 | 範圍失控、隨機粒子 |
| 人物主視覺 | 發光核心在人物／武器，結構光與粒子可佔約一半以上畫面；**臉、手、動作仍可辨** | 把「只准局部」套到大場面，畫面太弱 |
| 場景級爆發 | 源點唯一，光束／衝擊波／煙塵可跨大半畫幅，環境參與反應 | 白洞、中心與主體丟失、粒子方向亂 |

比例是藝術方向，不是硬閾值。

## §2 特效設計卡（每個特效必填）

一個鏡頭只有**一個主效果**；輔助效果共用主效果的源頭。

| 欄位 | 寫什麼 |
|---|---|
| 觸發 | 什麼事件／物體引發（劍刃擦石、掌心銅印引雷） |
| 空間錨點 | 固定在誰身上、身體哪個部位或場景哪個物件 |
| 覆蓋範圍 | 用畫面比例、身體部位或場景物件當相對尺度；不寫公分 |
| 形態與顏色 | 主形態、主流向、顏色家族 |
| 光照／遮擋／物理反應 | 照到誰的臉、手、衣料、地面；什麼被遮；碎片往哪飛 |
| 結束邊界 | 峰值後怎麼收：消散、落地、留痕、餘光；不能突然消失 |

**粒子**另寫：出生點、流向、近中遠三層的大小與密度、亮度／顏色遞減、消散或落點。破碎時粒子與碎石**共用同一撞點或力場**。一團均勻小點不算粒子特效。

**強光**另寫五層：最亮實體核心 → 次亮可見結構 → 空氣中的體積／霧光 → 人物與環境受光 → 有限的 bloom／light wrap。

持續特效（跨鏡存在的光刃、護盾、法相）還要寫：誰在維持、隨什麼移動、切鏡後狀態、收束觸發（承接武戲合同的持續特效生命週期）。

影片段寫「觸發前 → 峰值 → 消散或留痕」三拍因果，但這只是文字設計，不證明成片時序。

## §3 可讀性防線（不是身份鎖定）

- 保住五官與材質紋理；**bloom 只給最亮源**，light wrap 只在背光輪廓輕微溢光。
- 亮部要有亮芯和層次，暗部要保留；不寫成全屏白光。
- 次級層（煙、塵、碎點）不得遮住主效果或人物的臉、手、命中點。
- 術語（Niagara、Houdini、pyro、motion blur）不代表模型真的跑了模擬；每個術語旁邊要有看得到的描述。motion blur 不能代替軌跡、粒子或束線。
- 「全屏過曝閃白」在 H3 影片中是否可接受**尚未實測**；在測過之前，大招爆發寫「亮芯短閃、臉部保持可辨」。

## §4 生完怎麼判（看真實畫面，不打分）

正常觀看尺寸先看整體，依序：

1. **第一眼焦點與規模感**：主效果有沒有馬上抓眼？有沒有人物或建築當尺度參照？
2. **形態與方向力量**：粒子成流、煙有翻卷、碎塊有噴射方向、弧線或衝擊前沿清楚？
3. **明暗與色彩反差**：亮芯、結構光、霧光、暗部分得開？
4. **空間層次**：前中後景、遮擋、遠近密度差，效果進入場景而不是一層貼片？
5. **環境回饋與主體可讀**：地面反光、碎裂、塵霧、人物受光都圍繞同一源點，主體與命中關係可辨？

前兩項不行先修主視覺；五項都寫到但畫面平淡，仍是「部分通過：衝擊力不足」。白洞、碎點堆滿、主效果被雜亂淹沒＝返修。使用者的審美反饋優先於 Agent 判斷。結論寫進 `h3d verdict`（pass／warn／fail＋可見理由）。

## §5 返修對症

| 症狀 | 修法 |
|---|---|
| 太小、沒重量 | 改主形態跨度／厚度／縱深，保留尺度參照；不要平均放大所有元素 |
| 扁平 | 補前中後景與遮擋 |
| 泛白、白洞、蓋臉 | 收輝光，保亮芯與暗部，減弱遮臉的次級層 |
| 散亂、越修越亂 | 定唯一主事件 → 指定主形態 → 次級層共用源點並退後 → 刪無源元素 → 主事件可讀後才補亮度 |
| 像貼圖 | 補受光、接觸陰影、環境反應 |
| 縮小效果後殘留光 | 逐一點名殘留的表面（物體、地面反光、人物輪廓、空氣），寫出要恢復的原環境光與材質 |
| 同一失敗反覆出現 | 換實現方向；「改寫得更專業」不算改善（外部實測：熱扭曲堆專業詞兩次失敗） |

比較兩種寫法時凍結人物、機位、基礎光、配色，只改特效層；沒有固定種子就標「探索性」，不宣稱因果。

## §6 局部修正提示（remix／重抽修正時）

要刪或改畫面某部分時，**同時寫三件事**：保留區、刪除區、刪除後要恢復的表面與光照；用可見物體定位（「移除左下前景的大冰晶，恢復濕石板與倒影，保留杖尖小冰花」）。只寫「刪掉冰晶」容易殘留或誤刪。外部為單張圖實測有效，H3 影片未驗證。
