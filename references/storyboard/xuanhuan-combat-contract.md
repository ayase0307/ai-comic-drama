# 玄幻／武戲寫作合同

> 來源：外部「玄幻打鬥編導」技能（10 份文件）文字蒸餾，守富裁決併入（D21–D23、D26）。
> 證據等級：**創作者案例歸納，0 生成驗證**（只對 Seedance 做過文檔格式核對）。外部示例的 15 秒 8–15 鏡**不採用**：本專案 H3 段長維持 7–10 秒、2–4 拍，一拍可承載一組連擊。
> 與 `h3-combat-impact`（衝擊點、衝擊幀路徑）、`combat-and-vfx-library.md`（招式庫、五段鏈）並用；特效寫到什麼程度見 `vfx-design-and-review.md`。

## §1 先判斷這是哪種戰鬥（看接觸方式與空間，不看場景名）

| 分支 | 判定 | 必寫 |
|---|---|---|
| A 近身 | 兵器或肢體接觸 | 支點、腰胯、刃口方向、格擋與反擊的交疊 |
| B 遠程 | 離體攻擊對轟，或法器追殺與反制 | 法器三方位置（出手者、法器、目標），切鏡不重扔 |
| C 空戰 | 御劍、飛行 | 運動方向與鏡頭朝向分開寫 |
| D 巨物／獵獸 | 體型差大 | 巨物身體是移動地形、支點失效、巨獸反制、弱點進展 |
| E 群戰 | 一對多或多對多 | 敵人存活賬（見 `continuity-ledger.md` §1） |
| F 蓄勢 | 對峙、蓄力 | 蓄勢可以長，不套快打節奏 |
| G 宏觀大招 | 奇觀級 | 一句觀眾會記住的具體場面 |

同一段可切換分支，也可組合（C+D 法相摔蛇、B+C 法器追獵、E+F 結陣抗群）。

## §2 動作要成立

- **動作成立條件**：借壁折返要先有牆和蹬踏、空中變向要有借力點；條件不存在就換動作，不硬寫。
- **因果鏈**：局面 → 動作 → 回應 → 接觸或落空 → 可見結果 → 下一局面。
- **換打法要有觸發**：距離、傷勢、路線被封、對方應對，不按計時器換。允許單向鎮壓。
- **終結**：命中 → 體內傳播 → 整體失效 → 殘留；結果要給觀眾看清楚的時間。
- 選了的規則一定要出現在分鏡或提示詞正文；只寫在分析筆記裡等於沒做。

## §3 場地參與

寫場地條件如何改變動作空間與攝影：窄橋（只能縱向進退）、室內（牆柱可借力也會擋）、鬆散地表（滑步、揚塵）、濕石冰面（失衡）、水面水中、斷崖、雲海、移動平台。天氣與能量材質分清：沙漠裡出水柱要先交代水從哪來。

## §4 衝擊三層體量

| 層 | 畫面 |
|---|---|
| 擦碰 | 火星、刃口滑開、輕微退步 |
| 破防 | 護體凹陷、整個人被推退、地面拖痕 |
| 終結 | 雲壁被推開、地形改變、低頻震動 |

只寫「一級／二級／三級」或「超強」不算寫了；要寫看得到的結果。

## §5 鏡頭與速度用語

- 先定這一鏡的**觀察任務**（看清出手？看落點？看反應？）再選鏡頭，不做遠全中近特輪播。
- **運動方向與鏡頭朝向分開寫**（「攝影機向右平移，鏡頭朝左後看追兵」）。
- **Camera Roll（畫面旋轉）≠ Orbit（環繞）**；劍體自轉 ≠ 揮劍。
- **追人 vs 看落空**擇一並寫明：攝影機跟著攻擊者，還是停在原地看攻擊落空。瞬移與爆衝分開。
- **慢放／衝擊頓拍／停頓／定格是四件事**；全速場面靠推近、曝光、位移、震鏡、聲響強調，**不自動補 hit-stop**（H3 慢詞禁令照 `h3-combat-impact`）。角色被截停 ≠ 攝影機慢放。
- 無硬性 180° 規則：允許越軸，但要有過渡或用大全景重建空間。

## §6 大招

- 先寫一句具體場面（「劍光把整片雲海劈成兩半，露出下方城池」）。
- 六條設計路徑：實體角力、力量相剋、二次觸發、圍困收束、累積釋放、借勢連招。
- 過程鏈：起勢 → 成型 → 接近 → 接觸承壓 → 抵抗 → 決定性變化 → 結果。
- 尺度靠可見參照；巨物完整入鏡時攝影機要夠遠，不要求同一鏡同時塞巨物全身和人臉。
- 跨段的大招，接點選在「進行中狀態」。時長不夠就加段，不用小數秒硬塞。

## §7 附表（需要時才填）

**痕跡時序表**：發生階段｜狀態改變｜後續作用與結束條件（劍痕、焦土、裂地什麼時候出現、什麼時候消失）。

**部件去向表**（法寶變形）：原部件｜連續運動與新用途｜跨形態保留。先解除錨定再變形；手避開移動部件；能量核心位置全片一致；變形後不憑空多出第二把武器。「保留」＝跨鏡存在，不是每秒都看得到。

## §8 禁寫

空泛的「激烈／震撼／持續快打／保持連續」、「一二三級」、「滅世核爆」、「8K 60fps」或精確幀數當保證、「絕不崩壞」、含糊的「旋轉追拍」、沒看成片就寫「直出」。
