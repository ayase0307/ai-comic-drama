## 本機驗證紀錄

ffmpeg 7.1.5（sandbox）以 1080×1920／24 fps testsrc2＋正弦音實測通過：crop 震屏、白層 overlay 閃白、fade、zoompan、drawtext、sidechaincompress＋amix、xfade fadewhite、loudnorm（含 JSON 量測）、geq 放射線＋rotate 疊加、negate 衝擊影格、棕褐回憶、colorbalance 夜戲（注意參數是 bm 不是 ms）、lut3d＋blend、三層 overlay 視差、trim/setpts/concat 分段變速（輸出 4.00 s）、loop 定格（+1.21 s）、ASS 多樣式燒錄、登場卡合成（已抽影格目視）、最終匯出（h264 1080x1920 30fps／aac 48 kHz）。沙盒無 CJK 字型，中文字形未目視驗證。
