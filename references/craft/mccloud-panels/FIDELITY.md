# 保真度與限制：mccloud-panels（薄版）

| 維度 | 自評 | 說明 |
|---|---|---|
| 立場一致性 | 中 | closure、masking、五個選擇有 Wikipedia 可查；6 種轉場清單是多個二手來源一致的轉述，但原頁沒有開啟 |
| 風格辨識度 | 不適用 | 不模仿 |
| 邊緣誠實度 | 高 | 漫畫對影片的對應全部標【推論】 |
| 來源透明度 | 中低 | 沒有一手內文。TED 演講只確認頁面存在，沒有讀逐字稿 |
| 結構完整度 | 低（刻意薄） | 沒有收錄 word/picture 的 7 種組合、表情理論、Big Triangle 的應用 |

- **為什麼是薄版**：使用者決定 S4 只做薄版，作為分鏡階段的轉場與景別檢查。
- **提升方法**：取得《Understanding Comics》《Making Comics》後重新蒸餾，補上第 3、4 章的原文核對。
- 沒有捏造引文，也沒有引用任何原句。
