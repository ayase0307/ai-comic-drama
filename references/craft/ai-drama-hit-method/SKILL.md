# AI 漫劇爆款方法論（主題 lens）

> **適用範圍：只在短劇短集模式使用。** 本技能預設是長篇漫劇（整部一支連續長片、每個事件交代清楚）。
> 只有使用者明確選了短劇／竪屏爆款短集（`h3d decide series_format short`）時，本 lens 的 1–2 分鐘一集、
> 開場 5 秒鉤子、60 秒空窗、集尾鉤子等標準才適用。長篇專案跑 `hit_review.py` 會在報告開頭標明「僅供參考」。

> 本 lens 由 [女媧 · Skill造人術](https://github.com/alchaincyf/nuwa-skill) 的「主題 Skill」路徑生成。
> 調研時間：2026-10-21。來源見 `references/research/`。保真度與限制見 `FIDELITY.md`。

## 定位
這是一份**審查清單與思考框架**，不模仿任何一個人的語氣。它整合了邓骏、李振杰、九九、听花岛、陳珂的公開訪談、Save the Cat 節拍表，以及 2026 年的平台規範。

## 框架概覽：5 條共識
1. **受眾 → 內核 → 外殼**：先寫清楚給誰看、他們的情緒缺口是什麼，再決定故事內核，最後才挑世界觀和題材外殼。
2. **鉤子分三層**：全季（大懸念）、每段（小反轉）、每集結尾（期待）。如果要上付費平台，再加一層卡點。
3. **爽點是兌現承諾**：題材在開頭承諾了什麼（例如「反派不幹了」），就要盡早、反覆、每次換個方式兌現。打臉、人設反轉、主角俐落解決問題，都是兌現的方式。
4. **快慢結合**：戲點要放大（停頓、特寫、反應鏡頭），非戲點要壓縮。每一段都要帶著情緒，沒有情緒的段落就刪掉或併掉。
5. **AI 漫劇的「畫面感」權重更高**：選題和每一段都要問「這裡有沒有一個值得生成的畫面」；參考圖出戲，比劇情弱更致命。

## 回答工作流
1. **先跑腳本**：`python scripts/craft/hit_review.py --project-dir <P> --stage 3 --episode EP01`。腳本只輸出可確定的檢查，例如時間、欄位、字面合規。
2. **再做 Agent 審查**：讀劇本或 handoff，照下方清單逐項給「✅／⚠️／❌、證據（場次與台詞）、一句修法」，附加到報告的 `## Agent 審查` 段落。
3. **不改原檔**：只寫建議，修改要由使用者決定。

### Agent 審查清單
- [ ] **前提承諾**：一句話講出這集承諾觀眾什麼爽感，以及第一次兌現在幾秒。
- [ ] **開場鉤子**：前 5 秒內有沒有衝突或反常資訊。
- [ ] **人設反轉**：主角有沒有至少一次讓人意外的反應（例如反派用合規話術反殺系統）。
- [ ] **打臉／俐落解決**：對手壓迫後，主角有沒有用自己的方法乾淨地扳回。
- [ ] **非戲點**：哪些段落只是在交代資訊？建議壓縮，或改成帶衝突的「彈藥」。
- [ ] **集尾期待**：結尾留下什麼新問題，是新人物、新秘密，還是新威脅？
- [ ] **畫面感**：每場至少一個值得生成的畫面；有沒有純對話、沒有畫面的段落。
- [ ] **合規**：有沒有拜金、出軌等價值觀問題，或暴力畫面（可以改用台詞帶過）。
- [ ] **開場六步（只限 `series_format=short`）**：前 30–35 秒有沒有依序推進「異常事件 → 即時目標 → 致命規則 → 現實阻力 → 證據式反轉 → 未完成的答案」。長篇不套這個公式，只檢查「每條設定有沒有改變人物處境」。
- [ ] **阻力角色的利益（只限 short）**：擋路的人有沒有自己的利益（例如急著簽字是因為保險和債務），而不是為衝突而衝突。
- [ ] **證據式反轉（只限 short）**：反轉有沒有落在觀眾能立刻看懂、能跟主角一起確認的實物證據上（例如少了一枚婚戒），而不是一句解釋。
  - 以上三條來源 Foyege〈奧斯卡短劇節拍法〉（YouTube JeIop-z9sSs，創作者案例，未經本 repo 驗證；D45）。

## 反模式（審查時看到就標出來）
- 先挑熱門題材，再回頭找受眾。
- 一首 BGM 從頭鋪到尾，情緒不跟劇情走。
- 開場用旁白介紹世界觀，超過 5 秒都沒有衝突。
- 同一種爽點連續重複三次以上而沒有升級。
- 為了湊時長保留沒有轉折的段落。

## 誠實邊界
- AI 漫劇從業者的公開語料只有幾篇專訪，所以「AI 漫劇特有」的規則證據較弱。
- 數據與政策是 2026-10 的資料，平台規則變得很快，送審前要再查。
- 本 lens 不能預測一部劇會不會爆，只能檢查有沒有違反多數成功作品的共同做法。
