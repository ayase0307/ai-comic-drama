# 提示詞撰寫手冊

三條原則貫穿全篇：

1. **圖像提示詞寫「這一格長什麼樣」，影片提示詞寫「這幾秒怎麼動」。**
2. **固定片段原樣複製，可變部分才現場寫。** 角色／場景的固定描述片段來自 `assets.md`，不要改寫。
3. **本手冊產出的是「模型無關的主提示詞」。** 實際送進模型前，**必須先問使用者用哪個模型**，再依該模型改寫語法、語言與長度。對照表見 `references/model-profiles.md`；**MiniMax H3 有官方三段式結構，走 `references/minimax-h3.md`，不要套用本手冊公式。**

> 下面公式與詞彙表以英文為主，是為了給出可對照的基準。中文原生模型（即夢、可靈、混元、萬相）直接翻成中文更有效——但那是**改寫階段**的事，不要在這裡就把基準寫死。

## 一、圖像提示詞

### 結構公式

```
<固定角色片段> + <固定場景片段> + <本鏡畫面：人物在做什麼、在哪、朝哪> + <景別> + <光線時間> + <畫風關鍵詞>
```

各段用逗號分隔，**主體與動作放最前**（權重最高）。

### 景別詞彙

| 中文 | 英文 | 用途 |
|---|---|---|
| 大遠景 | extreme wide shot | 交代環境、規模 |
| 遠景 | wide shot | 人物與環境關係 |
| 全景 | full shot | 人物全身 |
| 中景 | medium shot | 腰部以上，最常用 |
| 中近景 | medium close-up | 胸口以上，對話 |
| 特寫 | close-up | 臉部，情緒 |
| 大特寫 | extreme close-up | 眼睛、手、細節道具 |

### 運鏡詞彙

| 中文 | 英文 | 效果 |
|---|---|---|
| 固定 | static / locked-off | 穩定、觀察感 |
| 推近 | dolly in / push in | 強調、聚焦情緒 |
| 拉遠 | dolly out / pull back | 揭示、抽離 |
| 橫移 | truck / tracking | 跟隨、空間關係 |
| 搖 | pan | 掃視環境 |
| 升降 | crane up / down | 規模感 |
| 環繞 | orbit / arc | 展示人物 |
| 手持 | handheld | 紀實、不安 |
| 跟拍 | follow shot | 動作連續 |

### 光線與時間

`清晨逆光` / `正午硬光` / `黃昏暖調` / `夜晚霓虹` / `月光冷調` / `室內頂光` / `燭光暖橘` / `陰天柔光` / `輪廓光` / `倫勃朗光`

### 畫風關鍵詞（鎖定後整部沿用，不要中途換）

- 日系賽璐璐：`anime screencap, cel shading, clean lineart, flat colors, vibrant`
- 厚塗寫實：`semi-realistic, painterly, soft shading, detailed textures`
- 國漫：`chinese manhua style, bold outlines, muted palette`
- 韓漫：`korean webtoon style, soft gradient, delicate lines`
- 水彩：`watercolor, soft washes, paper texture`

### 一致性技巧

- 角色固定片段**一個字都不改**；換裝時只替換「服裝」那一段，其餘照抄。
- 需要精準還原長相時，用**圖生圖**並提高風格貼合度，以角色參考圖為輸入。
- 同一角色在**不同集之間**也要用同一份片段——這是跨集一致性的唯一保證。

## 二、影片提示詞

影片提示詞**只描述運動與時間**。靜態外觀已經在首幀圖裡，重複描述只會干擾模型。

### 結構公式

```
<運鏡> + <主體動作與時序> + <環境動態> + <物理與連續感>
```

### 運動設計四要素

| 要素 | 寫什麼 | 範例 |
|---|---|---|
| **運鏡** | 攝影機怎麼動 | `鏡頭緩慢推近，最後停在中近景` |
| **時序** | 動作的先後與節奏 | `先是愣住半秒，接著猛然抬頭` |
| **主體運動** | 人物／物件的動作 | `她右手緩緩抬起，指尖輕觸照片邊緣` |
| **物理與連續感** | 布料、頭髮、光影的自然反應 | `風衣下擺隨動作輕擺，髮絲在晚風中飄動` |

### 範例

> 鏡頭從中景緩慢推近至特寫；林昭先是盯著照片不動，兩秒後手指微微顫抖，接著猛地抬頭看向門口；窗外霓虹光在她臉上掃過一次；風衣領口隨呼吸起伏。

### 進階控制

- **首末幀**：需要「鏡頭內有明確轉折」時，同時提供首幀與末幀圖，讓模型補中間過程。
- **單段時長**：4–8 秒最佳。要更長就拆鏡，不要硬拉。
- **音效**：可開啟生成音訊，但正式交付建議後期另配，控制力更好。
- **負面提示詞**：寫「避免什麼」，例如 `多餘手指, 面部扭曲, 畫面抖動, 文字水印, 角色換臉`。

## 三、常見失敗與修法

| 症狀 | 原因 | 修法 |
|---|---|---|
| 角色每鏡長得不一樣 | 固定片段被改寫，或沒用圖生圖 | 原樣複製片段；有角色就帶參考圖 |
| 畫風忽變 | 畫風關鍵詞漂移 | 把畫風詞寫進固定片段，整部鎖死 |
| 動作鬼畜、肢體扭曲 | 提示詞一次塞太多動作 | 一鏡一動作；拆鏡 |
| 影片像幻燈片 | 提示詞只寫了靜態描述 | 補上運鏡與時序 |
| 背景與人物風格打架 | 場景片段與角色片段風格詞不一致 | 統一畫風關鍵詞 |
| 手部／文字崩壞 | 模型通病 | 構圖避開手部特寫；文字交給後期字幕 |

## 四、提示詞檢查清單

出圖前逐條確認：

- [ ] 角色固定片段是否**逐字**來自 `assets.md`
- [ ] 場景固定片段是否**逐字**來自 `assets.md`
- [ ] 畫風關鍵詞是否與全片一致
- [ ] 景別是否與分鏡表一致
- [ ] 影片提示詞是否**只寫運動**、沒有重複外觀
- [ ] 是否寫了負面提示詞
