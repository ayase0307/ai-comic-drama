# 資產與一致性規範

角色設定圖、場景、道具、音色、風格與光色，**全部先於分鏡定稿**。圖像模型與 H3 共用這份規範。一致性靠「登記 + 參考鏈 + 驗收」，不靠模型記憶。

## 0. 先決定的三個衝突（本技能的裁定）

| 衝突 | 裁定 | 原因 |
|---|---|---|
| 有參考圖時，每鏡要不要重述外觀 | **有參考圖：外觀只在該角色首次出現的鏡頭寫一次，之後只寫新變化；沒有參考圖：逐字貼固定描述片段** | H3 手冊建議有參考時外觀只在首次出現寫、每鏡重述容易讓臉飄（`h3/shot-variety-and-staging.md` 自檢規則、`h3/references-and-editing.md`；皆非嚴格實測，出圖後仍要驗收）；沒參考圖時文字是唯一錨 |
| 九宮格同圖鎖臉 vs 逐鏡生成 | **九宮格只用在階段 2 的「關鍵幀鎖臉」（角色＋場景定調）；階段 6 一律逐鏡生成** | 九宮格是分鏡技能的前置鎖臉法，逐鏡才能個別重抽 |
| HEX 色票 vs H3「不用 HEX」 | **HEX 登記在 `assets.md` 當內部對照與 `color_qa.py` 驗收；餵 H3 時改寫成「色名＋物體」** | H3 對 HEX 無效（`h3/lighting-and-color.md`），圖像模型與驗收仍用得上 |

## 1. 資產 ID

分鏡 JSON、提示詞、檔名一律用 ID，中文名只作顯示。

| 前綴 | 對象 | 例 |
|---|---|---|
| `C-<slug>` | 角色 | `C-lin-zhao` |
| `W-<slug>-NN` | 服裝（每套一個 ID） | `W-lin-zhao-01` |
| `E-<slug>-<表情>` | 表情（選用） | `E-lin-zhao-cold` |
| `S-<slug>` | 場景 | `S-old-house` |
| `P-<slug>` | 道具 | `P-wooden-box` |
| `V-<slug>` | 音色 | `V-lin-zhao` |

每個資產帶**版本號**（`v1`、`v2`…）。檔名：`images/C-lin-zhao_W01_sheet_v1.png`。改動就升版本，舊版不刪。劇本層的 `character_id`（小說改編技能的故事聖經）與 `C-` ID 一一對應，不另造一套。

## 2. 全域鎖（寫在 `assets.md` 最前面，所有資產共用）

1. **風格鎖定錨**：從 `references/styles.md` 選一套，原文貼入。整部只用這一套，一次最多疊兩個風格。
2. **負面錨**：同上。
3. **全域光色句**：一句話描述整部的主光向、色溫、反差，逐字重用（`h3/lighting-and-color.md`）。
4. **五色色票**：膚、髮、主服、輔服、點綴，每色寫「色名＋HEX」。
5. `storyboard` Layer 2 的 `style_lock` 與這裡**同步**，改風格只改這一處再同步。

## 3. 角色設定板（Character Sheet）

**版面**：16:9 單張，平光、純色背景。左側 1 格面部特寫，右側 3 格全身（正面／側面／背面）。要 3/4 面時改 5 格。
**必備項**（缺一不過關）：

- 面部特寫：看得清五官、膚質、髮際、耳飾。
- 正／側／背全身，同比例、同站姿，雙手可見。
- 表情集（獨立一張或加在板下）：中性、微笑、怒、哭、驚、冷峻，共 6 張，同一張臉。
- 色票：五色，色名＋HEX。
- 身高對照：與主角或標準人形並排的剪影，標明身高（cm）。
- 服裝：**每套服裝各出一張全身三視圖**，ID `W-<slug>-NN`，並標明適用集數與劇本依據；沒有劇本依據不得換裝。
- 辨識錨：寫出 3 個「別人沒有的」特徵（如左眉尾疤、右手銀戒、髮簪形狀），之後每個鏡頭都要看得到。
- 板下附**固定描述片段**（逐字、可複製）。

**年齡段**：同一角色的少年／成年各出一套設定板，ID 用 `C-<slug>` 加版本標註年齡段，不得只改提示詞年齡。
**膚色衝突**：H3 的皮膚段預設「通透白皙」（`h3/skin-realism-block.md`）；角色膚色不同時，在 `assets.md` 該角色下寫**膚色覆寫句**，只換膚色形容，保留「真實肌理」部分。
**全身格鎖臉防崩鐵律（洋子規範）**：全身格專注鎖定頭身比與服裝剪裁，避免小比例全身臉畫崩造成與特寫格五官自相矛盾（必要時全身格可採純淨體態/弱化五官，臉部一律以左上特寫格為唯一基準）。

## 4. 場景主圖

- **全景母片**：一張定空間（家具位置、出入口、窗、主光源）。
- **三角度**：正向、側向、反向各一，同一空間。對話場景補一張過肩可用的背景虛化圖。
- **日夜／天氣變體**：同機位、同構圖，**只改光與色溫**，ID 加後綴 `-day`、`-night`。
- 板下附場景固定描述片段與**實體錨點家具**（如「站在紅木辦公桌右側邊角」），分鏡用它定站位。
- 場景的光色句要與全域光色句相容；不相容時場景句只能微調色溫。

## 5. 道具

- 正／側／細節各一，旁邊放**手掌或人物比例參照**。
- **狀態表**：完好／破損／已開啟…，每個狀態一張圖；寫明持有人與出現的鏡號。不可逆變化（杯子碎、信封皺）進 Layer 2 的 `persistent_world_state`，後續鏡頭一律承襲。

## 6. 音色鎖

- 每個有聲角色建 `V-<slug>`：**2–15 秒、單人、無配樂**的母帶，附原句文字與語氣說明。
- 試聽驗收：無他人聲、無底噪、語氣符合人設，使用者確認。
- 用法：H3 以 `[audio reference]` 掛同一份母帶；外部 TTS 則固定同一個聲線設定。細節見 `h3/audio-pipeline.md`。「跨片段鎖音色」在上游標為未驗證，產出後先聽。
- 情緒寫成文字（語速、停頓、氣息），不寫「聲帶閉合 45%」這類 H3 不吃的數值。

## 7. 參考鏈（哪一步用哪些圖）

```
角色設定板 ─┐
場景主圖 ───┼→ 分鏡圖（角色板 + 場景主圖作參考）→ 影片（首幀 = 已通過的分鏡圖）
道具圖 ─────┘
音色母帶 ──────────────────────────────→ 影片（Audio ref）
```

- 每步的參考圖張數**依模型上限**（H3：圖 ≤ 9、影 ≤ 3、音 ≤ 3、總 ≤ 12，見 `minimax-h3.md`）。圖像模型的上限先問使用者或查文件，不要猜。
- 用 Ref2VA（H3 參考生影片）時：圖 1 鎖臉與服裝；另一張只給光與氣氛；音檔給音色。
- 同一鏡的所有參考圖路徑記在 Layer 2 的 `reference_refs`，方便重現與重抽。
- **回寫**：通過驗收的分鏡圖或影片尾幀，可升版成新的參考版本，下一段承接它。

### 多模態素材職責表（防止交叉染色與特徵污染）

在多圖/多模態輸入（Ref2VA）時，嚴格遵循單一素材單一職責原則，禁止素材特徵溢出污染主體：

| 素材ID | 類型 | 唯一職責 | 必須保留 | 禁止影響 |
|---|---|---|---|---|
| `ref_image_1` | 角色設定板（特寫+全身） | 鎖定人物五官特徵、髮型、身形與服裝精確剪裁 | 面部五官幾何、髮型髮色、專屬辨識錨、服裝輪廓與色彩 | 禁止將純色設定板背景帶入成片場景 |
| `ref_image_2` | 場景主圖 / 空間底圖 | 確立物理空間幾何、建築材質、家具錨點與全局光源走向 | 牆面/地面材質、家具陳設、主光向與環境色調 | 禁止將場景材質染色到角色服裝或皮膚表面 |
| `ref_image_3` | 道具圖 / 特殊物件 | 鎖定關鍵道具比例、材質反光與破損狀態 | 道具形狀、握把尺寸、刻紋與不可逆物理狀態 | 禁止影響握持角色的服裝與體態 |
| `ref_audio_1` | 乾淨音色母帶 | 鎖定單人聲線音色、基頻與共鳴腔體質地 | 角色說話音色本質 | 禁止帶入母帶背景噪音或干擾環境擬音 |

## 8. 漂移偵測清單（每鏡生成後逐項 pass/fail）

臉型五官｜髮型髮色｜服裝件數與配色｜膚色｜標誌辨識錨 3 項｜道具位置與狀態｜光向｜色溫｜身體比例｜場景家具位置。影片另跑 `scripts/color_qa.py` 量跨鏡色彩。**任何一項 fail 就不得當下一段的首幀或參考。**

## 9. 修復階梯（由輕到重，一次只改一個變數，並記錄）

1. 原樣貼回固定描述片段（確認沒被改寫）。
2. 補上或換更乾淨的參考圖。
3. 有參考圖時，縮減外觀字數，只寫新變化（見 §0 第一項）。
4. 單變數重抽（只換種子、或只改一句提示詞）。
5. 升版本號：修正設定板，重出受影響的資產。
6. 請使用者人工裁定。

## 10. 每資產驗收門

| 資產 | 通過條件 | 驗收者 |
|---|---|---|
| 角色設定板 | §3 必備項齊全；使用者確認長相 | 使用者 |
| 場景 | 母片＋三角度＋所需日夜變體 | Agent 自檢＋使用者確認母片 |
| 道具 | 比例參照＋狀態表 | Agent |
| 音色 | 試聽通過，無他人聲與底噪 | 使用者 |
| 分鏡 | `scripts/storyboard/validate_storyboard.py` 通過；跨鏡 checklist（場景片段一致、角色 ID 一致、換裝有依據、同場光線一致） | Agent |
| 分鏡圖／影片 | §8 清單全 pass | Agent，存疑交使用者 |

沒通過就不進下一階段；階段 6 絕不拿未通過的資產當參考。
