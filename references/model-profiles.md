# 模型差異與生成前確認

## 為什麼要先問

提示詞**不是通用的**。同一個鏡頭餵給不同模型，要寫成不同樣子：

- **語法不同**：有的吃自然語言長句，有的吃逗號分隔標籤，有的支援權重與參數。
- **長度上限不同**：影片提示詞常見 2000–2500 字元上限；部分圖像模型只吃 75 個 token。
- **能力不同**：有的模型理解運鏡，有的只認動作；有的支援首末幀，有的只吃首幀。
- **語言偏好不同**：國產模型（即夢、可靈、混元、萬相）對中文更敏感；海外模型（Veo、Sora、Midjourney）建議用英文。

所以**每換一次模型，提示詞就要重寫一版**——不能拿 A 模型的提示詞直接餵 B 模型。

## 生成前必問（圖像、影片各問一次）

一次問完這四項，缺哪問哪：

| # | 項目 | 問法 |
|---|---|---|
| 1 | **用哪個模型 / 工具** | 「圖像你打算用哪個？影片呢？沒偏好我就照預設走。」 |
| 2 | **關鍵參數** | 畫面比例（9:16 / 16:9 / 1:1）、單段時長、解析度、是否帶音訊 |
| 3 | **提示詞語言** | 中文還是英文？依模型給建議 |
| 4 | **生成範圍** | 「先做前 N 鏡試水，還是整集跑？」 |

問完把**成本估算**一併講清楚，再開始生成。

> 這是**硬性步驟**：圖像、影片都一樣。沒問清楚不要呼叫生成工具。

## 圖像模型：提示詞風格對照

| 類型 | 代表 | 寫法 | 範例 |
|---|---|---|---|
| 自然語言敘事型 | GPT-Image、Gemini 圖像 | 完整句子，可描述情境與人物關係 | `A teenage girl with short black hair and a scar on her left eyebrow sits on an old sofa in a dim living room.` |
| 標籤堆疊型 | Midjourney、SD / Flux | 逗號分隔關鍵詞，可用權重與參數 | `1girl, short black hair, scar on left eyebrow, navy trench coat, medium shot, cinematic lighting --ar 9:16` |
| 中文原生型 | 即夢、通義萬相、混元 | 中文描述更自然，可保留中文專有名詞 | `短黑髮少女，左眉尾一道疤，藏青風衣，坐在舊沙發上，中景，室內暖黃燈光` |

**改寫要點**：
- 標籤型 → 把長句拆成短詞、去掉連接詞與冠詞、補權重。
- 敘事型 → 把詞堆補成通順句子，加入空間與情緒關係。
- 中文原生型 → 直接寫中文，不用硬翻英文。

## 影片模型：提示詞風格對照

| 模型 | 語言 | 特點 | 寫法建議 |
|---|---|---|---|
| Veo | 英文為主 | 對運鏡與電影語言理解好 | 描述性長句，明確寫出 camera move |
| Sora | 英文 | 敘事式，適合連續動作 | 用敘事句描述一段連續行為 |
| Runway Gen | 英文 | 偏好簡潔動作詞 | 短句，聚焦單一動作與運鏡 |
| Kling（可靈） | 中英皆可 | 中文友好，動作描述精準 | 中文寫運鏡與主體動作 |
| Seedance | 中英皆可 | 支援較長時長與首末幀 | 可寫較完整的分段動作 |
| **MiniMax H3**（Hailuo 3） | 中文友好 | **自帶一套官方三段式結構**，原生立體聲、口型同步 | **不可套用通用公式**，見下方專章 |
| MiniMax Hailuo（舊代） | 中文友好 | 中文自然 | 中文描述動作與氛圍 |

> **MiniMax H3 是例外中的例外**：它有官方規定的 `integrated_multimodal_description` / `overall_soundscape` / `non_diegetic_music` 三段式結構、四種模式（T2VA / I2VA / FL2VA / L2VA）、以及 `<d>` 台詞標記語法。寫 H3 提示詞前**必須**先讀 `references/minimax-h3.md`，不要用上面的通用公式硬套。

> 使用本環境內建生成能力時，實際底層模型由環境決定。**仍要先問使用者的偏好與參數**，再依上表改寫提示詞。

## 改寫流程

1. 先寫一版**模型無關的主提示詞**（就是分鏡表裡的 `image_prompt` / `video_prompt`），只描述畫面與運動。
2. 問清楚目標模型與參數。
3. 依對照表改寫成該模型的語法與語言。
4. 檢查長度是否超限、參數是否帶對。
5. 生成後檢視結果；不符預期就**改提示詞再重試**，不要盲目重跑。

## 回寫記錄

把每次生成用的模型與參數寫回分鏡 JSON，方便日後重現：

```json
{
  "shot_id": "S01-001",
  "image_model": "即夢 4.0",
  "image_params": { "aspect_ratio": "9:16", "style": "anime" },
  "video_model": "Kling 2.5",
  "video_params": { "seconds": 5, "resolution": "1080P", "enable_audio": false },
  "status": "video_done"
}
```
