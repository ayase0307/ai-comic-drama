# 七階段詳細流程

全程在 Agent 內部完成，不需要任何外部服務。每個階段都有明確產出物，落成檔案後再進下一階段。

---

## 階段 0：定調（Intake）

### 開工前必問清單

一次問完這六項，缺哪項問哪項：

| 項目 | 選項 / 說明 |
|---|---|
| 集數與每集時長 | 單集 1–3 分鐘最常見；短劇 60–90 秒 |
| 畫風 | 日系賽璐璐 / 厚塗寫實 / 國漫 / 韓漫 / 水彩 / 3D 渲染 |
| 畫面比例 | 9:16（豎屏短視頻，預設）／16:9（橫屏）／1:1 |
| 語言 | 旁白與對白語言，影響字幕與 TTS |
| 聲音形式 | 旁白解說 / 角色對白 / 兩者混合 / 全默片靠字幕 |
| 交付深度 | 只到分鏡腳本 / 到角色參考圖 / 到分鏡圖 / 到影片片段 |

若使用者沒說，採預設並**明確告知預設值**：單集 90 秒、日系賽璐璐、9:16、繁體中文、旁白解說、交付到分鏡圖。

### 產出 `project.md`

```markdown
# <專案名>

## 設定
- 集數 / 每集時長：
- 畫風：
- 畫面比例：
- 語言：
- 聲音形式：
- 交付深度：

## 一句話賣點
<主角 + 目標 + 阻礙>

## 分集規劃
| 集 | 標題 | 集內主事件 | 結尾鉤子 |
|---|---|---|---|
| 1 | | | |
```

## 階段 1：內容分析與分集

1. **抓主線**：一句話講清楚「誰、想要什麼、被什麼擋住」。
2. **找切點**：按事件轉折切集，每集結尾留鉤子（懸念、反轉、新問題）。
3. **配節奏**：豎屏短劇每 15–20 秒要有一次情緒起伏；單集 90 秒約 4–6 個節拍。
4. **控資訊量**：一集只講一件事。塞不下就拆集，不要壓縮。

**檢查點**：把分集表給使用者確認後再往下寫劇本。

## 階段 2：資產聖經（`assets.md`）

這是**整條線一致性的根基**。每個角色／場景／道具寫一段**固定描述片段**，之後每次生成原樣複製。

### 角色條目模板

```markdown
### <角色名>（<定位：主角／反派／配角>）
- **固定描述片段**（生成時原樣複製）：
  `<性別年齡>, <髮型髮色>, <瞳色>, <體型>, <標誌服裝>, <標誌配件>, <氣質關鍵詞>`
- **外貌要點**：
- **服裝**（日常／戰鬥／特殊場面各一套，並標明哪套用於哪些集）：
- **性格與口頭禪**：
- **人物弧線**：
- **參考圖**：`images/char-<角色名>.png`
```

> 固定描述片段要**具體到可畫**：「黑色短髮、左眉尾一道疤、藏青立領風衣、右手銀戒」。避免「很帥」「氣質高雅」這類不可視化的詞。

### 場景條目模板

```markdown
### <場景名>
- **固定描述片段**：`<空間類型>, <建築/環境特徵>, <主要色調>, <光源>, <時間與天氣>`
- **出現集數**：
- **氛圍關鍵詞**：
```

### 道具條目模板

```markdown
### <道具名>
- **固定描述片段**：`<材質>, <尺寸感>, <顏色>, <標誌細節>`
- **敘事功能**：<為什麼重要、出現在哪幾個關鍵鏡>
```

## 階段 3：分集劇本（`script-ep01.md`）

以**場次**為單位。每場標明時間、地點、人物、目的。

```markdown
# 第 1 集《<標題>》

## SC01 老宅客廳・夜・內
**人物**：林昭、林母
**目的**：建立主角處境與懸念
**內容**：
林母把一只舊木盒推到林昭面前。
林母：「你爸走之前說，這盒子要等你二十五歲那年才能開。」
林昭打開盒子——裡面只有一張泛黃的照片，照片上的人，是她自己。
**本場結尾情緒**：困惑中帶不安
```

寫作要點：
- 對白短，一句不超過 20 字（字幕可讀性）。
- 用動作代替形容詞：「他把杯子捏裂了」而不是「他很憤怒」。
- 每場結尾留一個「往下看」的理由。

---

## 階段 4：分鏡表

把劇本逐句拆成鏡頭。**欄位定義與 JSON schema 見 `references/storyboard-format.md`。**

拆鏡要點：
- 一個鏡頭＝一個動作或一句話，時長 2–6 秒。
- 對話用**過肩、特寫、反應鏡**交替，不要一直同機位。
- 情緒轉折處用**大特寫**或**空鏡**。
- 每集開頭 3 秒必須有視覺鉤子。

**檢查點**：分鏡表定稿後才進提示詞階段。沒定稿不出圖。

---

## 階段 5：提示詞包（`prompts-ep01.md`）

逐鏡產出兩條提示詞：

```markdown
### S01-003 ｜中景 ｜緩慢推近 ｜4s
- **圖像提示詞**：<固定角色片段>, <固定場景片段>, <本鏡畫面描述>, <景別>, <光線>, <畫風關鍵詞>
- **影片提示詞**：<運鏡>, <主體動作與時序>, <環境動態>, <物理連續感>
- **負面提示詞**：<要避免的東西>
```

**撰寫方法見 `references/prompt-playbook.md`。**

## 階段 6：生成

### 6.0 先問使用者要怎麼生成（圖像、影片各一次）

**這一步不可跳過。** 提示詞依模型而異，先確認再改寫。

| # | 問什麼 |
|---|---|
| 1 | 圖像用哪個模型／工具？影片用哪個？ |
| 2 | 關鍵參數：比例、單段時長、解析度、是否帶音訊 |
| 3 | 提示詞用中文還是英文？ |
| 4 | 先做前幾鏡試水，還是整集跑？ |

拿到答案後：把 `storyboard` 裡模型無關的主提示詞，**依目標模型改寫**（語法、語言、長度）。對照表與改寫流程見 `references/model-profiles.md`。

### 6.1 角色參考圖

每角色一張：正面、乾淨背景、中性表情、全身或半身。用圖像生成工具，提示詞＝固定描述片段 + 畫風關鍵詞。**給使用者確認後才繼續。**

### 6.2 分鏡圖

逐鏡生成。有角色出現的鏡頭，把對應角色參考圖作為圖生圖輸入以維持長相一致。

### 6.3 影片片段

優先**圖生視頻**：以分鏡圖為首幀，提示詞只寫運動。

- 需要「同一個鏡頭內的轉折」時，可同時給首幀與末幀圖。
- 單段建議 4–8 秒；超過就拆鏡。
- 生成需 1–3 分鐘，逐段做、逐段驗。

### 成本對齊（必做）

生成前把數量與估算告訴使用者：

> 本集 24 鏡，若全數出圖＋出片，約需 24 張圖（約 120–240 credits）＋ 24 段影片（約 1200–2400 credits）。要不要先做前 6 鏡試水？

---

## 階段 7：組裝與交付

1. **旁白稿**（`narration-ep01.md`）：逐鏡的旁白／字幕文字，標明時間碼。
2. **時間線**（`timeline-ep01.csv`）：`shot_id, start, end, video_file, subtitle, narration`。
3. **拼接**：可用 ffmpeg 合併影片片段、燒字幕、混 BGM 與配音。
4. **交付清單**：列出已生成檔案、未完成鏡號、成本估算。

```bash
# 範例：合併片段並燒入字幕
ffmpeg -f concat -safe 0 -i list.txt -c copy merged.mp4
ffmpeg -i merged.mp4 -vf "subtitles=sub.srt" -c:a copy final.mp4
```
