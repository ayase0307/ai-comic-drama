# 標準可拍漫劇劇本模板（Production Scene Script Template）

> **格式紀律**：
> 1. 保留 `第XX集｜集名`、`{集}-{場} {場景名} {時}/{內外}[（閃回）]`、`人物：`、`△` 動作行與 `角色名（括注）：對白` 格式。
> 2. 嚴禁在劇本正文中寫入攝影機景別／運鏡術語（如特寫、推鏡頭、切至）或 JSON 標籤。
> 3. 單句對白非空白中文字數建議 ≤ 28 字（上限 ≤ 35 字）。

---

```text
第01集｜回信

1-1 舊公寓客廳 夜/內
人物：林澈、沈寧
△昏黃的走廊燈隔著門縫照進客廳。桌上有一封被水浸濕的信，封口已經裂開。
△林澈站在桌邊，右手握住信紙，聽見門外傳來三下敲門聲。他迅速把信翻至背面。
沈寧（門外，壓低聲音）：開門。我知道你看過那封信。
△林澈的手僵住。信紙背面浮現一行他從未見過的暗紅色字跡。
林澈：這字……不是我寫的。

1-2 舊公寓走廊 夜/內
人物：林澈、沈寧
△木門門栓緩緩滑開一條僅容視線通過的窄縫，鐵鍊繃緊發出輕響。
△沈寧站在走廊陰影裡，右手按在腰間濕透的黑色封套上，目光穿過門縫鎖定林澈的右手。
沈寧：信封角上的火漆，還缺了一塊吧？
△林澈下意識蜷起右手食指，指腹下藏著半枚暗紅火漆碎屑。
林澈（平靜）：送信的人跳河前，就是這個樣子。
```
