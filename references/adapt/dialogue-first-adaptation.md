# 台詞優先改編規格（dialogue-first adaptation）

適用：任何小說→漫劇／短劇劇本改寫。**全程不詢問使用者「要怎麼改寫」**，開案和執行中都不問；以下預設就是最優解，直接執行。
出處與比較：`adaptation-evidence.md`。範例（《噩盡島 II》EP03）：`examples/edj2-ep03-before-after.md`。
工具：`scripts/adapt/dialogue_budget.py`（估時、預算、分集）、`scripts/adapt/adapt_gate.py`（自檢門）。

## 1. 固定預設（不問）
| 項目 | 預設 |
|---|---|
| 改寫方式 | **原著對白全保留、脫水不刪事件**。取代舊的台詞政策四選一（①逐字／②只留重點句／③影視化改寫／④純旁白），不再出題 |
| 原著裡可有可無的台詞 | 保留 |
| 原著只轉述、沒寫內容的對話（「對答了幾句」），或台詞太稀的場 | **允許補寫台詞**：符合人物、劇情與原著事實；每行行尾標 `<!-- invented -->`，並記入 `adaptation-diff.md`；不得違反原著設定、不得提前揭露懸念；補寫台詞不算原著對白覆蓋 |
| 旁白聲線 | **主角內心聲（男主內心獨白當 VO）**，不另設旁白員；VO ≤30% 可發聲字數，且不重複畫面已演出的資訊 |
| 語速 | 男主 4.0、女角／其他 4.5、旁白／畫外／內心 5.5 字/秒（沿用 PR #116） |
| 密度 | 3.0–3.6 字/秒 |
| 句長 | 目標 9–13 字，硬上限 35 字 |
| 單集長度 | 預設 150 秒（`--episode-seconds` 可改）；不超過 |
| 場次標題 | `N-M 地點 時段/內外`，時段只用 日／夜／晨／昏，內外只用 內／外 |
| 結尾 | 不加鉤子旁白；集尾停在原著台詞或動作 |
| 內容安全 | 全員成年、不性化 |

**執行中也不問**：新增原著沒有的事件、合併事件、改視角、提前揭懸念 → **預設禁止**；真的遇到時保持原著寫法，並把衝突記入 `adaptation-diff.md`（不是提案、不等核准）。補寫台詞是唯一允許的「新增」，規則見上表。

## 2. 階段
| 階段 | 做什麼 |
|---|---|
| A 逐章抽取 | 每章：概要、情節點（附原著行號）、**原著對白清單（逐字，`adapt_gate.source_quotes` 可自動抽「」）**、敘述／內心清單、未決項 |
| B 台詞預算分集 | 依 §3 公式在場次邊界分集（`dialogue_budget.py --split`） |
| C 逐場改寫 | 每場帶入口狀態、必發事件、出口狀態；先排行動鏈（目標→阻礙→行動→反應→調整→結果），再放台詞 |
| D 外化 | 依 §4 把敘述與內心轉成台詞、動作或內心 VO |
| E 自檢門 | `adapt_gate.py` 全部 FAIL 清零 |
| F 對帳 | 每集標 `<!-- source: 卷X Ln-Lm -->`；`adaptation-diff.md` 記補寫台詞與禁止項衝突 |

## 3. 台詞預算公式
- 每行秒數 t = 可發聲字數 ÷ 角色語速。
- 片長 L = Σt ＋ 0.3 s ×(行數−1) ＋ Σ刻意停頓（`△【停頓0.8】`，0.6–1.2 s，每集 ≤3 處）＋ Σ建立鏡（`△【建立2.0】`，≤2.5 s，每場 ≤1 處）。一般動作行和說話並行，不計時間。
- 密度 D = 可發聲字數 ÷ L，目標 3.0–3.6（<2.8 或 >3.9 FAIL）。
- 預算 = 目標秒數 × [3.0, 3.6]：150 秒 → **450–540 字**（約 41–49 行，每行以 11 字計）；125 秒 → 375–450；100 秒 → 300–360；90 秒 → 270–324。
- 純對白（女角 11 字一行）約 4.0 字/秒，所以每集需要約 10–25% 的停頓／建立鏡時間才落在 3.6 以下；說話時間佔片長約 75–90%。
- **分集**：從上一集終點依序累加整場。字數還不到下限（3.0 × 目標秒數）就接下一場，不在半途（例如「推門進房」）停；接下一場會超過目標秒數時，才在場次邊界切。整場放不下就整場移到下一集。
- 舊公式「台詞字 ÷ 4 × 1.6」只留作原著體量粗估，不再用來排每集長度。

## 4. 敘述轉台詞規則
1. **原著對白全保留**，只脫水：長句在語氣停頓處拆成同一人連續兩行，去語助冗字，不改意思（自檢門容許 ≥85% 字序對上）。
2. **角色口述的內容就是台詞**：原著寫成「緩緩地解釋著」「交代了幾句」而有內容的講解、命令、轉述，改回該角色的台詞，不寫成旁白。
3. **內心獨白**：先外化成一個動作加一句台詞，或讓旁人說出口；外化不了才用主角內心 VO（`名（內心）：…`），只承擔畫面給不出的東西：反差判斷、隱藏打算、跨時間認知。
4. **世界觀／設定敘述**：用主角內心 VO，每集 VO ≤30%；楔子集若超過，在對帳表註明。設定盡量放到它第一次影響角色選擇的那集。
5. **只轉述、沒寫內容的對話**：補寫 1–3 行符合人物與事實的台詞，標 `<!-- invented -->`；內容不得新增劇情事實或洩露懸念。
6. VO 不重複畫面已演出的資訊；台詞已說清的，下一場不再演一次。
7. 不加結尾鉤子旁白（「下集…」「究竟…？」）。

## 5. 自檢門（`adapt_gate.py`）
| # | 檢查 | 門檻 | 級別 |
|---|---|---|---|
| G1 | 原著對白覆蓋（本集範圍，補寫不算） | 100% | FAIL |
| G3 | 密度 | 3.0–3.6；<2.8 或 >3.9 | WARN／FAIL |
| G5 | 單行字數 | ≤35 FAIL；平均 >13 WARN | FAIL／WARN |
| G6 | 內心／旁白 VO 佔比 | >30% | WARN |
| G7 | 連續無台詞 | >5 s WARN、>10 s FAIL | WARN／FAIL |
| G9 | 場次標題格式、片長 ≤ 目標秒數、無集尾鉤子旁白 | 規格 | FAIL |
| G10 | 內容安全：全員成年、不性化（未成年／性化關鍵詞掃描，另需人工確認人物表年齡） | 0 命中 | FAIL |
| G12 | 原著出處範圍 `<!-- source: … -->` | 必填 | FAIL |
| 記帳 | 補寫台詞行數 | 須寫入 `adaptation-diff.md` | WARN |

```bash
python scripts/adapt/dialogue_budget.py --episode-seconds 150            # 只印預算
python scripts/adapt/dialogue_budget.py script/ep01.md --male-lead 主角名 --split
python scripts/adapt/adapt_gate.py script/ep01.md --source-text source/ch01_part.txt --male-lead 主角名
```
