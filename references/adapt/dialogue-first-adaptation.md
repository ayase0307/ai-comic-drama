# 台詞優先改編規格（dialogue-first adaptation）

適用：任何小說→漫劇／短劇劇本改寫。**全程不詢問使用者「要怎麼改寫」**，開案和執行中都不問；以下預設就是最優解，直接執行。
出處與比較：`adaptation-evidence.md`。範例（《噩盡島 II》EP03）：`examples/edj2-ep03-before-after.md`。
工具：`scripts/adapt/dialogue_budget.py`（估時、列出分集斷點）、`scripts/adapt/adapt_gate.py`（自檢門）。

## 1. 固定預設（不問）
| 項目 | 預設 |
|---|---|
| 改寫方式 | **原著對白全保留、脫水不刪事件**。取代舊的台詞政策四選一（①逐字／②只留重點句／③影視化改寫／④純旁白），不再出題 |
| 原著裡可有可無的台詞 | 保留 |
| 原著只轉述、沒寫內容的對話（「對答了幾句」），或台詞太稀的場 | **允許補寫台詞**：符合人物、劇情與原著事實；每行行尾標 `<!-- invented -->`，並記入 `adaptation-diff.md`；不得違反原著設定、不得提前揭露懸念；補寫台詞不算原著對白覆蓋 |
| 旁白聲線 | **主角內心聲（男主內心獨白當 VO）**，不另設旁白員；VO ≤30% 可發聲字數，且不重複畫面已演出的資訊 |
| 語速 | 男主 4.0、女角／其他 4.5、旁白／畫外／內心 5.5 字/秒（沿用 PR #116） |
| 密度 | 3.0–3.6 字/秒 |
| 句長 | 目標 9–13 字，硬上限 35 字 |
| 單集長度 | **不設上下限**。一集只是一次分鏡的斷點，最後全部串成一支；`--target-seconds` 只回報參考值，不擋 |
| 分集斷點 | 停在自然的故事點（換場、揭曉、轉折），可在任何一句之後；每個斷點記 `<!-- episode-end: 「原著逐字錨點」 | 這集為什麼停在這 -->`（ArcReel 式，見 §3） |
| 場次標題 | `N-M 地點 時段/內外`，時段只用 日／夜／晨／昏，內外只用 內／外 |
| 結尾 | 不加鉤子旁白；集尾停在原著台詞或動作 |
| 內容安全 | 全員成年、不性化 |

**執行中也不問**：新增原著沒有的事件、合併事件、改視角、提前揭懸念 → **預設禁止**；真的遇到時保持原著寫法，並把衝突記入 `adaptation-diff.md`（不是提案、不等核准）。補寫台詞是唯一允許的「新增」，規則見上表。

## 2. 階段
| 階段 | 做什麼 |
|---|---|
| A 逐章抽取 | 每章：概要、情節點（附原著行號）、**原著對白清單（逐字，`adapt_gate.source_quotes` 可自動抽「」）**、敘述／內心清單、未決項 |
| B 選斷點分集 | 依 §3 在自然故事點選斷點、寫錨點與理由（`dialogue_budget.py --split` 列出各集） |
| C 逐場改寫 | 每場帶入口狀態、必發事件、出口狀態；先排行動鏈（目標→阻礙→行動→反應→調整→結果），再放台詞 |
| D 外化 | 依 §4 把敘述與內心轉成台詞、動作或內心 VO |
| E 自檢門 | `adapt_gate.py` 全部 FAIL 清零 |
| F 對帳 | 每集標 `<!-- source: 卷X Ln-Lm -->`；`adaptation-diff.md` 記補寫台詞與禁止項衝突 |

## 3. 台詞預算公式
- 每行秒數 t = 可發聲字數 ÷ 角色語速。
- 片長 L = Σt ＋ 0.3 s ×(句數−1) ＋ Σ刻意停頓（`△【停頓0.8】`，0.6–1.2 s，每集 ≤3 處）＋ Σ建立鏡（`△【建立2.0】`，≤2.5 s，每場 ≤1 處）。一般動作行和說話並行，不計時間；原著無台詞動作 beat 必標【動作】（下方），它有自己的鏡頭秒數但不進 L。
- **句數不是行數**：句間 0.3 s 依句末標點（。！？…；）計。同一人連續兩句合成一行（#120 單句 ≤18 字）或拆成兩行，L 與密度都不變（EP01 實測：舊算法合併後少 0.3 s，G3 3.88→4.02 FAIL）。在逗號處拆行會多一個氣口，照多一句算。
- **分鏡後預估片長**（`storyboard_seconds`，`adapt_gate` 列 NOTE、只回報不擋）：用分鏡閘門同一套數字再算一次——每句鏡長＝字數÷角色語速＋0.3 s（#116 說話窗口，句內每多一句再加 0.3 s），最低 `h3_spec.MIN_SHOT_SEC`（1.2 s）；每場依 ≤10 s 分段、每段 17n+5 取整平均多半個量子（約 0.35 s，inferred）；含【動作】鏡（v118 EP01 沒標動作時：劇本估 195 s、分鏡實作 224.9 s）。G3 仍用上面的 L（門檻是依 L 校準的）。
- **【動作】標記（原著無台詞動作 beat，必標）**：原著裡沒有台詞、必須獨佔畫面的動作（巨鳥掠過、爆炸、墜坡、吞人），**每個主要動作標一行** `△【動作】…`，需要時給秒數 `△【動作2.5】…`（未給 2.0 s，最短 `MIN_SHOT_SEC`）。**一個標記＝一個主要動作＝分鏡裡獨立一鏡**：多步動作拆成多行，例如吞鳥鏡寫成三行
  ```
  △【動作2.3】巨鳥俯衝，一口咬住洛年的手。
  △【動作2.3】巨鳥把洛年甩上半空。
  △【動作2.4】洛年落進巨鳥的喉嚨。
  ```
  不要寫成一行「咬住、甩起、吞下」（噩盡島 EP01 失敗案例：片長照台詞時間反推，三個動作只分到 2.2 s，成片角色被拋起又掉回地上、沒被吞）。和說話並行的小動作（點頭、轉身、遞東西）照舊寫一般 `△`，不標。
  - 標記**不算台詞、不進 L**，不影響 G3 密度與 G7 無台詞區間；`adapt_gate` NOTE 列出【動作】鏡數，G14 檢查漏標與一行塞多個動作（見 §5）。
  - 往後一路強制：`sync_script.py` 把劇本先後寫進 handoff `script_sequence`；`handoff_to_skeleton.py` 每個標記排成獨立一鏡（`source_action: true`、`action_mark`），鏡長＝標記秒數，台詞估時、`--duration-policy fit` 都不壓縮，段 ≤10 s 裝不下就另開段、不截短；`validate_storyboard` D5 核對標記數（遺失／併進台詞鏡／被截短）、D6 擋一鏡塞 ≥3 個動作；D1–D4 與 `pacing_gate` 的台詞類檢查不計動作鏡（`references/storyboard/cinematic-director.md` 台詞密度閘門）。
  - 不加標記的舊劇本，估時、分鏡骨架與閘門結果都和以前一樣。
- 密度 D = 可發聲字數 ÷ L，目標 3.0–3.6（<2.8 或 >3.9 FAIL）。原著對白全保留時 3.6–3.9 只出 NOTE、不算 WARN：不刪原著對白，也不為壓密度多加停頓／建立秒數（v118 實測）。停頓每集 >3 處、建立每場 >1 處由 `adapt_gate` 出 WARN。
- 密度是**速率**，不是每集字數額度；集長多少都用同一個 3.0–3.6 檢查。要估某段多長，可用 `--target-seconds` 換算參考字數（秒數 × 3.0–3.6），純資訊。
- 純對白（女角 11 字一行）約 4.0 字/秒，所以每集需要約 10–25% 的停頓／建立鏡時間才落在 3.6 以下；說話時間佔片長約 75–90%。
- **分集（ArcReel 式斷點）**：集長不設上下限，不為湊長度接下一場，也不為壓長度把整場移走。
  - 斷點選在自然的故事點：換場、揭曉（停在揭曉前一秒或剛揭曉）、轉折、一段對話告一段落。可在場內任何一句之後；場被切開時，下一集沿用同一場次標題。
  - 每個斷點寫在該集最後一行之後：`<!-- episode-end: 「錨點」 | 理由 -->`。錨點是 2–30 字、在原著段落中逐字出現的片段（標出這集原著停在哪），理由一句話說明為什麼停在這。
  - 出處：ArcReel `lib/prompts/prompt_templates/templates/text/episode_plan.md` L67–80（每集給 hook「這一刀為什麼切在這」＋ end_anchor 原文逐字 10–30 字；找不到劇情弧完整的切點就不硬切）、`lib/episode/episode_target_duration.py` L1–6、L25–28（單集目標時長選填、軟偏好、不做硬阻斷）。
  - 理由只寫在註解，不變成鉤子旁白。
- 舊公式「台詞字 ÷ 4 × 1.6」只留作原著體量粗估，不再用來排每集長度。

## 4. 敘述轉台詞規則
1. **原著對白全保留**，只脫水：長句在語氣停頓處拆成同一人連續兩行，去語助冗字，不改意思（自檢門容許 ≥85% 字序對上）。
2. **角色口述的內容就是台詞**：原著寫成「緩緩地解釋著」「交代了幾句」而有內容的講解、命令、轉述，改回該角色的台詞，不寫成旁白。
3. **內心獨白**：先外化成一個動作加一句台詞，或讓旁人說出口；外化不了才用主角內心 VO（`名（內心）：…`），只承擔畫面給不出的東西：反差判斷、隱藏打算、跨時間認知。
4. **世界觀／設定敘述**：用主角內心 VO，每集 VO ≤30%；楔子集若超過，在對帳表註明。設定盡量放到它第一次影響角色選擇的那集。
5. **只轉述、沒寫內容的對話**：補寫 1–3 行符合人物與事實的台詞，標 `<!-- invented -->`；內容不得新增劇情事實或洩露懸念。
6. VO 不重複畫面已演出的資訊；台詞已說清的，下一場不再演一次。
7. 不加結尾鉤子旁白（「下集…」「究竟…？」）。
8. **原著無台詞動作 beat 標【動作】**：原著兩句台詞之間的動作敘述，要獨佔畫面的每個主要動作標一行 `△【動作】…`（多步動作拆多行，見 §3）；和說話並行的小動作寫一般 `△`。

## 5. 自檢門（`adapt_gate.py`）
| # | 檢查 | 門檻 | 級別 |
|---|---|---|---|
| G1 | 原著對白覆蓋（本集範圍，補寫不算） | 100% | FAIL |
| G3 | 密度 | 3.0–3.6；<2.8 或 >3.9 | WARN／FAIL |
| G5 | 單行字數 | ≤35 FAIL；平均 >13 WARN | FAIL／WARN |
| G6 | 內心／旁白 VO 佔比 | >30% | WARN |
| G7 | 連續無台詞 | >5 s WARN、>10 s FAIL | WARN／FAIL |
| G9 | 場次標題格式、每個斷點前都無集尾鉤子旁白（集長不檢查） | 規格 | FAIL |
| G13 | 分集斷點 `episode-end`：至少一個；錨點 2–30 字且在原著段落逐字出現；理由非空 | 規格 | FAIL（未給原著段落時錨點只 WARN） |
| G10 | 內容安全：全員成年、不性化（未成年／性化關鍵詞掃描，另需人工確認人物表年齡） | 0 命中 | FAIL |
| G12 | 原著出處範圍 `<!-- source: … -->` | 必填 | FAIL |
| G14a | 一行【動作】描述 ≥3 個主要動作（依子句數：標點與「然後／接著／隨即」切開、含動作動詞的子句算一個） | 拆成多行，一個標記一個主要動作 | WARN |
| G14b | 有 `--source-text` 時：劇本相鄰兩句台詞在原著之間的敘述有 ≥2 個動作子句，劇本這兩句之間卻沒有【動作】行；或原著 ≥3 個動作子句且超過【動作】行數兩倍。「」內文字與劇本說話人名先拿掉（避免專有名詞誤報）；啟發式，確認是和說話並行的小動作可忽略 | 補標或拆行 | WARN |
| 記帳 | 補寫台詞行數 | 須寫入 `adaptation-diff.md` | WARN |

```bash
python scripts/adapt/dialogue_budget.py --target-seconds 90              # 只印參考字數（純資訊）
python scripts/adapt/dialogue_budget.py script/ep01.md --male-lead 主角名 --split
python scripts/adapt/adapt_gate.py script/ep01.md --source-text source/ch01_part.txt --male-lead 主角名
```
