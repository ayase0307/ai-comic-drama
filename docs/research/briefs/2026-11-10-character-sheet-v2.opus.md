1. **現行版式本來就是「左胸像＋右三全身」**：`scripts/storyboard/export_asset_prompts.py:79` 的 `MASTER_COMPOSITION`，胸像約 40%。老大給的狐仙構圖只是把比例改成 35／65，不需要換版式。

## 1. 角色設定板 v2 版式

**定案：沿用左胸像＋右三全身，比例改成 35／65。不採 director-master 的反向排法。**

不採反向排法的原因有兩個：
- 老大自己給的狐仙構圖就是左胸像。
- 下游全部綁這個順序：`panel_label_en`（最右是背面、中間是四分之三側）、編譯器輸出的 "fourth figure from the left"、E20／E27 門禁、裁切預設框。反過來排，這些會一起錯。

**「塗掉正臉」和「保留胸像」可以並存：生成後再處理，不叫模型畫無臉人。**
- 叫模型「不畫臉」會出無臉人或面具臉，影片模型會把它當成角色特徵學進去。
- 做法是照常出完整四格板（人審、存檔都看這張），再用固定步驟產生兩份衍生檔：
  - `-face.png`：胸像裁切。這是唯一的臉部參考，進 `face_subject_ids`。
  - `-body-masked.png`：三個全身格的頭部用背景灰填平。查表模式（`reference_view: "panel"`）一律綁這張。
- 這樣「正面臉不匯入」就不再只靠提示詞拜託，像素上真的沒有臉。§7.4 和 §11 待驗清單裡最大的風險，在設定板這端就先降下來。
- E20／E27 不用改：遮臉板仍是板的尺寸，照樣要宣告 panel 和格位。

**版面規格**

| 項目 | 定案 |
|---|---|
| 畫布 | 16:9，目標 2560×1440 |
| 左格 | 0–35%，頭到肩正面胸像；臉高 ≥ 512px，不夠就提高解析度，不改比例 |
| 右格 | 三格均分：正面／45° 斜側（臉朝畫面右）／180° 背面 |
| 對齊 | 頭頂一線、腳底一線；同站姿，雙臂微離身，雙手可見 |
| 背景與光 | 四格共用淺灰無縫棚底；均勻平光；無投射陰影、無輪廓光、無頂光；同一焦平面 |
| 禁用 | 底部細節區、文字、標籤、色票、HEX、刻度、邊框、分隔線、水印、第二個人、道具、場景、第五格 |

**只有風格句和畫質句可以變。** 構圖句和防呆句寫成程式常數，用簡中，跟現有提示詞同語言：
- ① 胸像只畫頭到肩，跟右側三格不重疊。
- ② 三個全身站姿相同，雙手完整可見。
- ③ 四格共用淺灰無縫背景；沒有環境、道具、地面投影；平光，沒有投影、輪廓光、頂光。
- ④ 所有視圖同一焦平面，全部清晰。
- ⑤ 畫面只有這四個視圖：沒有底部區、文字、標籤、色卡、邊框、水印，也沒有其他人。
- ⑥ **附肢句**，只在卡片填了附肢時才加：「〈附肢〉共 N 條，固定從〈部位〉長出；三個全身格數量與位置一致；收攏在身後，不遮雙臂與雙手；背面露出根部。」
  - 九尾沒有這句的話，尾巴會蓋住雙手和背面特徵，跟 ② 互相打架。
- 現有的「背面至少三項特徵」規則保留。

**§3.1 的必備項要跟著改寫，不然會跟「無底部區」衝突：**
- 表情集改成另一張圖 `E-<slug>-set`（3×2 六格），仍屬必備。
- 色票、身高（cm）、三個辨識錨改成 `assets.md` 卡片的文字欄位，不進圖。
- 身高剪影降為選用。

## 2. 一致性機制

- **原樣沿用**：固定描述片段、辨識錨、色票（餵 H3 時照舊改寫成「色名＋物體」）。
- **新增卡片欄位**：`身高`、`附肢`（種類、數量、連接部位、收合方式）。
- **服裝 W-NN**：每套照舊一張，改用 v2 版式，檔名 `_sheet_v2`。舊的 v1 板不刪。
- **`TEMPLATE_VERSION`**：從 `master-4view-v1` 改成 `sheet-v2`，裁切預設框依這個值選。噩盡島這類舊專案繼續用 v1 的框，不用重出。
- **不需要新的 `schema_version`**：
  - `SCHEMA_VERSIONS` 只管四種 JSON，沒有設定板格式。
  - manifest 原本就有 `template` 欄位。
  - 卡片新欄位都是選填。
  - 唯一要確認的是 `references/schemas/` 有沒有列舉 template 的值；有的話只加 enum，不升版。

## 3. 道具規範（改寫 §5）

**版式**：
- 左約 60%：一張 3/4 斜俯主圖，道具完整入畫、四周留白。
- 右約 40%：一個 2×2 正方塊，正面／右側／背面／正上方。扁平物的「正上方」改成斜上 45°。
- 背景和光同角色板。

**提示詞分段**：主圖／四向／構造／材質／尺寸／風格／不要。段名是我自己取的，不沿用來源；正文用簡中。
- 「不要」的固定內容：人、手、身體部位、動物、第二件道具、雜物、文字、標註線、數字、刻度、水印、邊框、第五個角度。

**跟現行 §5 的取捨**：
- **手掌參照拿掉。** repo 自己就有證據：§7.4 那句 "A pointing hand enters from offscreen" 被 H3 畫成一整個第二人。比例改由「尺寸」段的 cm 提供，需要看比例尺就在模型外補。
- 正／側／細節三張，改成主圖加四向。
- **狀態表保留**：每個狀態一張同版式的板，ID 加後綴（`P-x-broken`）。
- 送影片時一樣只給單視角裁切（定律三）。

## 4. 場景規範（改寫 §4）

**定案：兩邊合併。**
- 每張場景圖都是單機位、單瞬間、不分格。
- 「全景母片 → 單獨反打 → 正＋反當參考，再生側面／俯視」的分步流程保留，每個角度都是獨立的一張圖。

**分段**：
- 主場景：機位高度、朝向、取景範圍，以及前、中、後三層縱深。
- 光線：直接引用全域光色句。拿掉現行模板寫死的 `cinematic volumetric lighting`，它會跟全域光鎖打架。
- 錨點：家具和門窗都貼牆，並寫明開或關。
- 材質：跟 §0 的材質錨點逐字同步。
- 留位：留出走位要用的空地，但畫面裡沒有人。
- 風格。
- 不要：人、人影、手、動物、文字、水印、方位標、分格、第二個機位。

場景比例照舊跟 `aspect_ratio` 走。
