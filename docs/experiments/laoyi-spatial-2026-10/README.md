# 老易空間邏輯實驗（2026-10）：場景母片、牆面分配層、構圖板

測試外部創作者「老易」的空間邏輯做法（平面圖、分鏡板、場景表、提示詞方位層）能不能降低 REMIX／H3 成片的空間錯位（座位錯、門窗換牆、場景漂移、生物棚拍背景外洩），提高抽卡可用率。
製作專案：《噩盡島》自助餐店場景，文戲 EP90 S01-a～d（4 段）、武戲 EP91（＝EP05 S02-b～d，3 段）。家機 REMIX（MiniMax H3，pdd480・4 步、16:9、無 LoRA），同 seed 比較。

由此產生的技能規則：`references/storyboard/spatial-consistency.md`；可選工具：`scripts/storyboard/wall_map.py`。

## 限制（引用前必讀）

- **評分只有一人**（Hark），看關鍵幀接觸表＋密集抽幀，不是看整支影片；「可用」是剪接角度的主觀判斷，有少數邊緣案例。
- **部分盲評**：各段打亂、盲碼評完才解碼，但部分組別畫面特徵一眼可辨（武戲 H／I 的碎盤破洞、D′ 板子風格；第一批到件順序可推組別）。
- **樣本小**：每組文戲 8 段次，±25 個百分點只等於 2 段次；武戲每組 6 段次，只當方向。
- **兩批場景包不同**：第一批與第二批座位錯不可直接相比；A′ vs A 只用來看「換母片」本身的效果。
- **非單一變數**：武戲 H−A′ 混了場景文字、打鬥後狀態與拋飛方向句；F／G−A′ 混了場景表與物理規則區塊；I−F 因 7000 字元上限精簡了介紹句。
- 單一場景（自助餐店）、單一模型（H3 via REMIX）；其他場景型態未驗證。
